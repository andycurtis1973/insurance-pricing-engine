The real loop · lookalike prior → test offers → confirm → price

How the engine prices a shopper it has never seen

A new shopper lands. Step one: look up what real people like them bought — a warm start from demographics. But that only guesses coverage; it can't tell who'll walk on price. So step two: float a few test offers and read the responses. Step three: those clicks confirm the persona. Step four: lock the price. Set a profile and run one through.

The lookalike prior (step 1) is REAL — 96,882 Allstate shoppers. The shopper's hidden persona is drawn from that cell's real mix; their responses to test offers are modeled (calibrated + disclosed). It shows the mechanism.
